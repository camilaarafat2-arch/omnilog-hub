
# Planejamento Scrum — OMNILOG HUB

## Sprint 1 — Planejamento e banco de dados
**Duração:** 2 semanas

- Definir requisitos e casos de uso.
- Elaborar o DER.
- Criar as tabelas iniciais.
- Configurar o repositório Git.
- Validar o modelo de dados.

**Entrega:** documentação inicial e banco estruturado.

## Sprint 2 — Núcleo e aplicação desktop
**Duração:** 2 semanas

- Implementar classes de domínio.
- Criar algoritmos de rotas e armazenagem.
- Desenvolver telas de cadastro.
- Integrar a aplicação desktop ao banco.
- Executar testes unitários iniciais.

**Entrega:** módulo desktop e algoritmos básicos funcionais.

## Sprint 3 — Portal web
**Duração:** 2 semanas

- Criar o catálogo de produtos.
- Implementar cadastro e autenticação.
- Desenvolver pedidos e consultas de estoque.
- Implementar rastreamento de entregas.
- Integrar o portal ao banco de dados.

**Entrega:** portal web integrado em ambiente de teste.

## Sprint 4 — Testes e entrega
**Duração:** 2 semanas

- Executar testes de caixa preta e caixa branca.
- Corrigir defeitos encontrados.
- Validar segurança e desempenho.
- Documentar instalação e uso.
- Preparar apresentação em português e inglês.

**Entrega:** versão integrada, testada e documentada.

## Definition of Done — DoD

Uma tarefa é considerada concluída quando:
- O código atende aos critérios definidos.
- O código foi revisado.
- Os testes previstos foram executados.
- Os defeitos impeditivos foram corrigidos.
- A documentação foi atualizada.
- A alteração foi integrada à branch adequada.
