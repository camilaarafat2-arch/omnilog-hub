
# OMNILOG HUB
## Documento de Visão do Projeto

### 1. Identificação

**Empresa:** OmniLog Solutions S.A.  
**Sistema:** OmniLog Hub  
**Curso:** Técnico em Desenvolvimento de Sistemas (TDS)  
**Turma:** TDS Tarde  

### 2. Contextualização

A OmniLog Solutions S.A. atua no setor de logística
internacional e distribuição varejista. Com a expansão
das operações, a empresa necessita de uma plataforma
integrada para centralizar informações de clientes,
produtos, estoque, pedidos, pagamentos e entregas.

### 3. Objetivo geral

Desenvolver uma plataforma corporativa integrada que
permita administrar operações logísticas e comerciais,
desde a compra de produtos até o acompanhamento da entrega.

### 4. Objetivos específicos

- Gerenciar clientes e funcionários.
- Cadastrar produtos e categorias.
- Controlar estoque e posições de armazenagem.
- Registrar pedidos e pagamentos.
- Calcular rotas e custos de entrega.
- Permitir o rastreamento de encomendas.
- Disponibilizar uma aplicação desktop para operações internas.
- Disponibilizar um portal web para clientes.
- Garantir integridade e segurança dos dados.
- Registrar operações importantes para auditoria.

### 5. Público-alvo

- Clientes.
- Operadores de armazém.
- Gerentes logísticos.
- Administradores do sistema.

### 6. Escopo do sistema

O sistema será composto por:
1. Módulo de algoritmos logísticos.
2. Banco de dados relacional.
3. Aplicação desktop corporativa.
4. Portal web de e-commerce e rastreamento.
5. Módulo de testes, segurança e auditoria.

### 7. Benefícios esperados

- Centralização das informações.
- Redução de erros operacionais.
- Melhor controle de estoque.
- Maior visibilidade das entregas.
- Agilidade no processamento de pedidos.
- Melhoria na segurança e na rastreabilidade das operações.

### 8. Limites do projeto

Integrações reais com transportadoras internacionais,
pagamentos bancários e serviços externos dependerão
da disponibilidade de APIs, credenciais e ambientes
de teste. Quando não estiverem disponíveis, serão
utilizadas simulações documentadas.

### 9. Resultado esperado

Uma solução integrada e funcional, documentada e testada,
com módulos web e desktop conectados ao banco de dados,
respeitando os requisitos definidos para o projeto.
