
# OMNILOG HUB

Sistema Corporativo Integrado de Gestão Logística,
Cadeia de Suprimentos e E-commerce Omnichannel.

## Objetivo
Integrar o gerenciamento de clientes, produtos,
estoque, pedidos, pagamentos e entregas.

## Módulos
- Planejamento e documentação
- Algoritmos e orientação a objetos
- Banco de dados relacional
- Aplicação desktop
- Portal web
- Testes de software
- Versionamento com Git
- Documentação técnica em português e inglês
